# Infinix X668C Kernel Builder (GitHub Actions)

Repositori ini otomatis mengompilasi kernel Linux 5.4.147 untuk **Infinix X668C (Hot 12 Pro / F162)** dengan konfigurasi otentik pabrik.

## Cara Menjalankan:
1. Buka tab **Actions** di GitHub.
2. Klik workflow **Build Infinix X668C Kernel** di menu sebelah kiri.
3. Klik **Run workflow** -> pilih branch `main` -> klik tombol hijau **Run workflow**.
4. Tunggu proses build selesai (~15 - 20 menit).
5. Download hasil file artifact bernama `infinix_x668c_kernel`.
6. File di dalam zip artifact langsung dinamai `kernel`, siap dipakai di MIO-KITCHEN!
